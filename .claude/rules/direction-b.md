# Creative Direction B: "Vintage Warmth"

*Updated 2026-04-17: primary brand color reconciled from Thicket Green (#4A5D4E) to Tiki (#317B73) to match shipped implementation. Decision by Luis (Avenida Web Design).*

Acknowledges the 1940s/1950s inspiration overtly while avoiding "tiki-bar" kitsch. Draws from mid-century modern stationery, Palm Springs architecture, and vintage automotive catalogs.

## Color Palette

Warm, earthy tones that complement skin tones and retro environments in Susana's work.

| Token | Name | Hex | Usage |
|-------|------|-----|-------|
| `--color-bg` | Parchment | #EFE9D9 | Background. Feels like high-quality vintage paper stock. |
| `--color-primary` | Tiki | #317B73 | Headings and primary buttons. Mid-century-meets-tropical anchor color. |
| `--color-accent` | Terracotta | #BC6C25 | Subtle links or icons. Touch of warmth. |

## Typography

| Role | Font | Weight | Notes |
|------|------|--------|-------|
| Display | League Spartan | Bold | Geometric sans-serif referencing mid-century advertising and signage. Bold, friendly, structured. |
| Body | Crimson Text | Regular | Classic book-style serif. Makes About and Velvet Gazette feel like reading a physical publication. |

## Homepage Hero

- Hero image is **not** full-bleed — set within a wide, generous border of Parchment (#EFE9D9).
- Framing makes photography feel like a physical print or book page.
- Logo centered at top using bold League Spartan.
- **CTA:** Framed button below the image — "Book a Session."

## Gallery / Portfolio Page

- **Layout:** Classic masonry grid with consistent 20px spacing.
- **Borders:** Thin 1px line in Tiki (#317B73) around images — emphasizes "printed" aesthetic.
- **Categories:** Tab system mimicking vintage file folders.

## Gains and Sacrifices

- **Gains:** Direct alignment with subcultures Susana serves (Rockabilly, Tiki, Vintage). Feels personal, warm, and highly curated.
- **Sacrifices:** The "photography as high art" focus. UI elements are more visible, taking a larger portion of viewer attention.
